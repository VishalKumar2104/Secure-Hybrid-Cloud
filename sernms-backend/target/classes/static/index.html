⚡ Controlled Academic Demonstration & Fault Injection Lab

This interactive testbed allows evaluators to simulate real-world failure events in the hybrid infrastructure and immediately inspect how SERNMS detects the failure, fires threshold alarms, alerts administrators, and logs immutable audit trails.

Scenario 1: Network Edge Router Failure

Simulate hardware/power failure on R-EDGE-01 (10.10.0.1). Watch the topology node turn red and a Critical ICMP alarm trigger.

Scenario 2: AWS EC2 CPU Utilization Spike

Simulate CPU spike to 94.8% on EC2 Instance i-07f9c81a2b. Demonstrates CloudWatch metric breach > 90% threshold.

Scenario 3: Hybrid IPSec VPN Tunnel Failure

Sever the Site-to-Site IPSec VPN tunnel between Campus Router and AWS VGW. Verifies hybrid tunnel failover alert.

Scenario 4: Access Switch SW-ACC-01 Degraded

Set SW-ACC-01 into WARNING state. Verify yellow status halo in topology visualizer.
